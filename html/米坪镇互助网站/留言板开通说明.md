# 米坪镇生活通 · 留言板开通说明

## 一、先说原理（很重要）

这个网站是**纯静态网站**（托管在 GitHub Pages，没有服务器和数据库）。
所以"留言板"的留言数据不能存在网页文件里，而是借用一个叫 **Twikoo** 的开源评论系统，把数据存在云端。

要开通留言板，一共就三件事：

1. **部署一个 Twikoo 后端**（免费），得到一个"环境 ID"（下面叫 `envId`）；
2. 把这个 `envId` 填进网站的 `app.js`；
3. 打开留言板，设置一个**管理员密码**，之后你就能在后台删帖、审核。

下面一步步来。

---

## 二、选一个部署平台（三选一）

| 平台 | 是否免费 | 国内访问 | 说明 | 推荐 |
| --- | --- | --- | --- | --- |
| **Netlify** | ✅ 免费 | 不错 | 免费额度充足，国内能访问，需要 MongoDB Atlas 数据库 | ✅ **推荐** |
| 腾讯云（云开发） | ❌ 需付费 | 最快 | 国内最快，但要花钱买环境 + 实名认证 | 想要最快就选它 |
| Vercel | ✅ 免费 | 慢 / 可能打不开 | 免费，但国内访问不稳定 | 不推荐国内用 |

> 说明：官方已**不推荐**"腾讯云一键部署"——它免费额度不够留言板用，用完会扣费。所以免费方案首选 Netlify。

---

## 三、推荐路线：Netlify 部署（免费）

### 第 0 步：注册 MongoDB Atlas，拿到"数据库连接字符串"

1. 打开 <https://www.mongodb.com/cloud/atlas/register>，用邮箱注册（免费）。
2. 创建免费 **M0** 集群（Cluster），地区选离你近的（如新加坡 / 香港），一路默认即可。
3. 进入 **Database Access**，新建一个数据库用户（用户名、密码自己设，记住它们）。
4. 进入 **Network Access**，点 **Add IP Address**，选 **Allow access from anywhere**（`0.0.0.0/0`），确认。
5. 回到 **Database**，点 **Connect → Drivers**，复制那串连接字符串，形如：
   `mongodb+srv://你的用户名:你的密码@xxxxx.mongodb.net/?retryWrites=true&w=majority`
   （把里面的 `你的用户名`、`你的密码` 替换成第 3 步设置的，**密码不要带 `@` 等特殊符号**）

> 更详细的图文教程见官方文档：<https://twikoo.js.org/mongodb-atlas.html>

### 第 1 步：注册 Netlify 并部署 Twikoo

1. 打开 <https://app.netlify.com>，用 GitHub 账号登录（没有 GitHub 就先用邮箱注册一个 GitHub）。
2. 打开 <https://github.com/twikoojs/twikoo-netlify>，点右上角 **Fork**，把它复制到你的 GitHub 账号下。
3. 回到 Netlify，点 **Add new site → Import an existing project → Deploy with GitHub**，授权后选择你刚 fork 的 `twikoo-netlify`。
4. 在 **Environment variables** 里点 **Add**，Key 填 `MONGODB_URI`，Value 填第 0 步拿到的连接字符串，然后 **Deploy**。
5. 部署完成后，点 **Domain settings**，设置一个你自己的三级域名，比如 `miping-liuyan`，最终得到 `https://miping-liuyan.netlify.app`。

### 第 2 步：得到你的 envId

你的 envId 就是：

```
https://你的域名.netlify.app/.netlify/functions/twikoo
```

例如：`https://miping-liuyan.netlify.app/.netlify/functions/twikoo`

> 验证：在浏览器打开这个地址，如果页面显示 **"Twikoo 云函数运行正常"**，就说明部署成功了。

---

## 四、把 envId 填进网站

1. 打开网站根目录的 `app.js`。
2. 找到最上面这一块：

```js
const GUESTBOOK = {
  envId: "",
  region: ""
};
```

3. 把 `envId` 填上（Netlify 填完整地址，`region` 留空即可）：

```js
const GUESTBOOK = {
  envId: "https://miping-liuyan.netlify.app/.netlify/functions/twikoo",
  region: ""
};
```

4. 保存，重新上传到 GitHub Pages（或刷新本地预览）。留言板就出现了。

> 如果你选的是**腾讯云**：`envId` 填"环境 ID"（形如 `xxx-1gxxxxxx`，不带 `https://`），`region` 填 `ap-shanghai` 或 `ap-guangzhou`。
> 如果你选的是 **Vercel**：`envId` 填 `https://xxx.vercel.app`（没有后缀），`region` 留空。

---

## 五、设置管理员密码（删帖 / 审核用）

1. 打开网站，滚到留言板，右下角会有一个**小齿轮**图标。
2. 点它，按提示**设置管理员密码**（一定要记住）。
3. 以后点齿轮登录，就能看到"管理"面板：删帖、审核、置顶都在里面。

> 建议开启管理面板里的"**垃圾评论过滤**"和"**私密评论**"等开关，能挡掉大部分广告。

---

## 六、常见问题

- **留言板显示"正在开通中"** → 说明 `envId` 还没填或填错了，检查 `app.js`。
- **显示"加载失败"** → 网络问题，刷新重试；或换国内 CDN（见下）。
- **能显示但发不出留言** → 检查 MongoDB 的 Network Access 是否放行了 `0.0.0.0/0`，以及 Netlify 环境变量是否填对后点了 Redeploy。
- **国内加载慢** → 前端脚本默认已用国内镜像（npmmirror），一般没问题；也可换 `https://s4.zstatic.net/npm/twikoo@1.7.22/dist/twikoo.all.min.js`。
