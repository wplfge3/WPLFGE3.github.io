# 萸老头 · 伏牛山道地药材 品牌站

西峡县米坪镇行上村道地药材品牌「萸老头」的品牌展示与营销网站。单页长滚动结构，纯静态
（HTML + CSS + 原生 JS），不依赖构建工具、不需要后端，双击 `index.html` 即可打开。

- 品牌主体：南阳晟行农业发展有限公司
- 产地：河南省南阳市西峡县米坪镇行上村
- 品牌创立：2025 年春（金星）
- 主打产品：野生山茱萸（萸肉）、九蒸九晒黄精，另有伏牛山天麻、连翘、土蜂蜜、西峡香菇

页面板块（单页顺序）：首屏 → 信任条 → 品牌故事 → 道地产区 → **产地密码** → 道地药材 →
抖音专卖店 → 古法工艺 → 科研依据 → 从山头到餐桌 → 食用指南 → **银发经济** → 直播助农 →
媒体报道 → 批发合作 → 常见问题 → 联系与订购 → 页脚。

## 四、内容合规提醒（重要，请务必读完）

这一版给页面加了两块"有分量"的内容：**科研依据**（引用 12 篇公开文献）和**银发经济**（引用国家政策与统计数据）。
它们能大幅提升可信度，但也最容易被人挑毛病，所以下面这些边界请守住。

### 4.1 三条文献红线（`#research` 板块）

1. **不许写「等级越高、有效成分越足」。** 找不到可核验的、按商品规格等级做成分对比的研究；
   能核验的只有**产地差异**研究。媒体的"肉厚色正、有效成分足"只能作为转述媒体说法，
   不能挂到文献下面。
2. **不许写「九蒸九晒最好」。** 三篇论文给出的最优炮制次数互不相同（三蒸三制 / 6 次 / 8 次抗氧化最高）。
   页面刻意把这处分歧写出来，反而最可信，**不要删**。
3. **不许把文献结论说成产品功效。** 卡片只写"研究结论"，产品侧只写产地、等级、工艺、批次这些
   可验证的事实，中间不建因果桥。底部声明与 FAQ 已覆盖这一点，不要删。
4. 想再加文献：题录必须可核验（有 DOI 或能在知网/PubMed 检索到），结论必须忠实于摘要，
   并同步更新 `资料与文案台账.md`。**宁可少一条，不要加一条查不到的。**

### 4.2 三条银发经济红线（`#silver` 板块）

1. **不许写「银发经济占 GDP 约 6%」「2035 年占约 10%」。** 这两个数字查不到官方原文，属媒体转述。
   页面用的是可核验的第三方测算（联合国开发计划署与兴业证券），并已明确标注"非政府文件数据"。
2. **不许写「河南是药食同源试点省份」。** 国家卫健委没有公开发布统一的试点省份名单。
   页面只讲 2023 年**已正式列入目录**这一确定事实。
3. **银发经济与"药食同源"没有直接挂钩的国家文件。** 国办发〔2024〕1 号全文没有"药食同源"四个字，
   写的是"中医药养生保健"和"适合老年人的保健食品"。页面用词与原文一致，别自行升级表述。

### 4.3 产地密码板块的三条红线（`#terroir`）

1. **不许把「伏牛红心」说成我们的品种。** 它是河南省农业科学院西峡分院等单位选育的良种，
   不等于萸老头基地的树都是这个品种。页面已明确写出这一点，**删了就变成虚假宣传**。
2. **不许写功效，一个都不行。** 尤其是《中国药典》对山茱萸的功能主治（"补益肝肾，收涩固脱"）
   和"滋阴补阳"这类说法：前者是药品口径，后者连专业上都错（山茱萸是补肝肾兼收涩，
   **不是补阳药**）。张锡纯更著名的那几句（"救脱之功，较参、术、芪更胜"）属于疗效表述，
   页面**一句都没引用**——只引了他关于"去核"的那句**加工要求**。
3. **不许把本草记载写成产品功效。** 页面把它框定为"中医药历史文化"并配了免责声明；
   "六味地黄丸里有它"那句也限定为"它是这些经典方剂里的一味原料药"。

> **最容易犯的错**：把《中国药典》的功能主治搬到商品页上。山茱萸虽是药食同源物质，
> 但作为食品销售时，页面写"功效"即违反《广告法》第十七条与《食品安全法》第七十三条。
> 想要"让产品显好"，走产地（`#origin` / `#terroir`）、工艺（`#craft`）、
> 文献（`#research`）、规格与性价比（`#products` 里的「一斤萸肉够喝多久」）这四条路，比写功效有效也更安全。

### 4.4 其他

- **不要给连翘加食用或功效描述。** 它不在"既是食品又是药品的物品名单"，也不在"可用于保健食品的物品名单"，
  页面对它的定位就是给药企和饮片厂的原料。
- **产品分级、检测报告、资质证书**建议尽快补充图片。特别是山茱萸的马钱苷/莫诺苷含量测定报告——
  有了它，"科研依据"就能从"行业研究"落到"这一批货"，说服力再上一个台阶。
- **数据要跟着原文更新。** 产地、产能、交易额等数字引自公开报道（见「媒体报道」板块），
  报道口径与统计时间不同可能不一致，建议每年复核一次。
- 页面已包含国家卫健委关于"适量食用、孕妇哺乳期妇女及婴幼儿等特殊人群不推荐食用"的官方表述，
  以及"不能代替药物、不承诺功效"的提示，**请勿删除**。

## 七、可继续做的扩展

1. **产品详情页**：把弹窗内容拆成独立页面（`products/cornus.html` 等），更利于搜索引擎收录。
2. **在线成交**：接入微信小程序 / 有赞 / 抖音小店的购买入口，或加一个“加微信下单”的浮层二维码。
3. **表单落地**：现在的表单是 `mailto:` 方案（无后端）。若要真正收单，可接到企业微信、飞书表单、
   金数据或自建接口，把 `app.js` 里 `initForm()` 的跳转逻辑换掉即可。
4. **溯源展示**：把“一品一码”的扫码结果页做成一个页面，客户扫码即可看到批次与检测信息。
5. **视频优化**：`miping-promo.mp4` 约 46 MB，建议转成 H.264 + 720p（约 5–8 MB）或上传到视频平台后
   改为嵌入播放。
